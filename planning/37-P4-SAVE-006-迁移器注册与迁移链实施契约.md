# P4-SAVE-006 迁移器注册与迁移链实施契约

- **文档编号：** planning/37
- **状态：** 实施冻结；按负责人 2026-10-19 委托采用 `planning/35` 推荐项，裁决见 `planning/36`
- **上游：** `Save & Compatibility Specification v1.0.md` §§5.2–5.3、8、9、15；`planning/22`；`planning/34`；`planning/35`/`planning/36`
- **本包：** SAVE-006；仅做注册、纯内存链查找、计划构建与对 SAVE-005 类型的转换

## 1. 边界

允许新增 `crates/save-manager/src/migration.rs` 和 `crates/save-manager/tests/migration_contract.rs`，并在 `src/lib.rs` 加 `pub mod migration;`。不得改 SAVE-001~005 冻结实现/签名、Kernel、platform-core、Cargo 依赖、CI 或 DC-10 白名单。模块不访问文件、网络、时钟、环境、进程或迁移代码；不执行迁移。执行、事务、回退、运行时确定性探针及故障报告适配器分别留给 SAVE-007/后续装配层。

## 2. 公共数据模型

所有公开载体实现 `Clone + Debug + Deserialize + Eq + PartialEq + Serialize`，集合使用有序容器，JSON 使用 serde 默认结构；错误实现 `Display + Error`。

- `MigrationDomain`：带标签的 `World { game_definition_id: String }` 或 `Mod { mod_id: String }`。World owner 必须匹配存档 `manifest.game_definition.id`；Mod 域 ID 即 owner。两个域即使版本相同也隔离。
- `MigrationDataScope { world: bool, mods: BTreeSet<String> }`。
- `MigrationVerification`：`round_trip`、`golden_digest`、`custom` 三种稳定 snake_case wire 值。
- `MigratorDescriptor`：完整承载规范 §8.1 的 12 项声明：`id`、`domain`、`from_schema`、`to_schema`、`migrator_version`、`requires`、`input_scope`、`output_scope`、`changes_world_data`、`has_irreversible_ops`、`resource_budget`、`verification`。除 ID、域 owner、端点、requires 外其余声明只承载、不解释；跨 Mod scope 声明不导致拒绝。
- `MigrationChain { hops: Vec<MigrationHop> }`；`MigrationHop` 直接复用 SAVE-005 已冻结类型，禁止改其字段。
- `PlannedMigration` 保存完整描述符快照。
- `MigrationPlan { save_id, source_root_hash, steps }`；步骤先按域稳定排序，再保持域内迁移链顺序。serde JSON 对同一输入逐字节稳定。
- `MigrationTargets { world_schema_version, mod_schema_versions }`：World 目标必填，Mod 目标由装配层为当前已安装的存档内 Mod 注入。缺少已安装 Mod 目标返回显式计划输入错误；不得静默跳过。真正未安装的存档 Mod 交由 SAVE-009。不得由 Kernel 快照格式推导 World Schema。

## 3. 注册契约

入口：`MigrationRegistry::build(Vec<MigratorDescriptor>) -> Result<MigrationRegistry, MigrationRegistryError>`。构建后不可变。迁移器 ID 全局唯一；同域同 `(from_schema,to_schema)` 唯一。输入顺序不影响注册表序列化与查找。

拒绝空白/空 ID、空 owner、非法 SemVer 迁移器版本、`from_schema == to_schema`。允许显式降级边；不推断逆向，不因图含环而拒绝。校验与冲突检查稳定排序；若多项错误，返回稳定排序后的首项。

稳定错误码：`DuplicateMigratorId` → `save.migration.duplicate_migrator_id`；`ConflictingMigrationEdge` → `save.migration.conflicting_edge`；`InvalidDescriptor` → `save.migration.invalid_descriptor`。冲突携带域、端点与两个 ID；非法声明携带可选 ID、字段和稳定原因字面值。

## 4. 查找契约

入口：`find_path(domain, from, to, installed_mod_ids: &BTreeSet<String>)`。`from == to` 返回空链。按 `(to_schema,migrator_id)` 稳定 DFS 枚举简单路径（路径内版本节点不得重复）。每条边的 `requires` 必须全部属于已安装 ID 集合；不满足则剪枝并记录有序 `(migrator_id, missing_dependency)`。

最多收集 3 条有效链。仅当收集到第 3 条时停止并设 `truncated=true`；此字段只表示搜索未穷尽、完整性未知，不表示已证明存在第 4 条。收集 0 或 1 条必须穷尽；恰有两条也继续至穷尽。两条及以上均返回歧义错误，候选链按 hop ID 序列排序；`truncated=false` 时候选集完整。无有效链但有不兼容候选返回 `IncompatibleStep`，否则 `NoMigrationPath`。不设搜索预算（接受的指数最坏复杂度风险登记于 SAVE-006/SAVE-012）。

稳定码：`NoMigrationPath` → `save.migration.no_path`；`AmbiguousMigrationPath` → `save.migration.ambiguous_path`；`IncompatibleStep` → `save.migration.incompatible_step`。错误 wire `code` 为稳定码，字段排序确定。

`to_compatibility_path(Result<&MigrationChain, &MigrationLookupError>)` 将成功链（包括空链）映射为 `MigrationPath::Available(Vec<MigrationHop>)`，任一查找错误映射为 `MigrationPath::Unavailable`。不得修改 SAVE-005；调用方保留原始错误供 SAVE-011 诊断。

## 5. 计划构建

入口从 `InspectedSave`、注册表、`MigrationTargets` 与已安装 Mod ID 集构建。World 查询域 owner 取 Manifest `game_definition.id`；仅在 world schema 有差异时查链。Mod 查询仅对 Manifest 中且当前已安装的 Mod 查链；缺少其目标版本是显式输入错误，未安装的存档 Mod 由 SAVE-009 处理。任一查询失败则整体失败，不返回部分计划。计划包含 `save_id`、完整性报告中的 `root_hash` 和每一步完整描述符快照；无差异时返回空 steps。构建不执行迁移、不写入存档。

## 6. 验收测试

在 `migration_contract.rs` 覆盖：ID/边冲突、各字段非法、降级边、直达/多跳/空链/缺失、requires 剪枝及不兼容诊断、域隔离、菱形和含环歧义、有界候选三种 truncation 情况、唯一路径穷尽、注册顺序扰动的稳定序列化、SAVE-005 三值转换、计划排序/元数据/重复构建字节一致、错误稳定码，以及 DC-10 零 I/O。每个错误变体都断言 wire 稳定码。不得只以单元内部 helper 测试代替公开 API 契约测试。

## 7. 缺口与交付声明

SAVE-006 只证明迁移声明静态完整性和查找算法自身可重复；不证明迁移代码执行期确定性（GAP-24(c)）。`platform.mod.migration_failed` 装配层适配器尚不在本包（GAP-25）。World Schema 权威目标值来源仍缺（GAP-27），本契约仅规定调用方注入。以上均不得宣称关闭。迁移 ABI/执行规范也不由本包定义。

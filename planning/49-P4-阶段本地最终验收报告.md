## 受限 Wasm migration ABI v1

新增 `game_platform::migration_runtime::WasmMigrationRunner` 并实现 SAVE-007 `MigrationRunner`。ABI 只接受零 imports 模块，公开固定三页线性内存及 `migrate` 导出；页面 0 留给 guest 静态区，页面 1/2 为宿主输入/输出缓冲区；每方向上限 64 KiB。每次迁移新建 Store、Fuel 上限 1,000,000、内存总量上限 192 KiB，不开放 WASI、文件、网络、进程、系统时钟、随机或 Kernel 可变 World。输入/输出 JSON 结构有闭合 Schema `schemas/migration-abi-v1.schema.json`，未知字段拒绝；SAVE-007 继续执行 Scope 校验、世界快照校验、跨 Mod 引用校验、摘要复验与原子提交。

该 ABI 是 P4 新增的迁移接口，不修改 P3 既有运行时 Host API 目录/清单格式，也没有增加宿主能力导入。
